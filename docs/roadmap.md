# Roadmap

## Current scope

- Validated CSV register
- Explainable use-case prioritization
- Indicative capacity estimate
- Review signals and a stakeholder decision brief
- Synthetic demonstration data

## Future scope

- Sensitivity analysis over uncertain assumptions
- Optional persistence and assessment history
- A dashboard for workshop facilitation
- Automated test coverage for parsing and scoring boundaries

Future scope is intentionally separate from current capabilities. The current CLI is a local prototype, not a hosted product.
